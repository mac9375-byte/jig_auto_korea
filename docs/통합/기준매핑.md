## 4. 요약

- **사내 기준이 있는데 코드가 어기는 것: 2건** (`bot_relief_offset` 하한 0, jigauto `comp_clearance` 0.5)
- **사내 기준이 있는데 구현이 없는 것: 10건** (§2)
- **코드에 있는데 근거가 없는 것: 3건** (`THRU_TOOL_DIAMETER`, `THRU_MERGE_GAP`, `PIN_CLEARANCE_DIAMETER`)
- **치구 유형(31종)별로 값이 갈리는 기준이 많다.** 단일 전역 상수로 둘 수 없고, 선택된
  BASE JIG 유형에 따라 룰 집합을 고르는 구조가 필요하다 — `rules.json`의 `jig_type`
  필드가 이미 그 축을 갖고 있다.

## 5. 적용 치구 확인 (2026-11-18)

§2 의 10건을 `rules.json` 의 jig_type 으로 확인했다. app.py 가 만드는 치구(TAPE 부착 JIG, SMT수대)에
해당하는 것은 **DSG-005-03(4배열, 구현 완료)** 과 **DSG-011-02(살대 3mm, 자동화 모델 조건부 — 사용자 확인 대기)** 뿐이다.
가이드핀·가이드 블럭·뜰채·브릿지 7건은 **라우터 JIG**, 탈착핀은 **FPCB 부착 JIG**, 하단 살대는 **자동화 설비**
기준이라 app.py 에 적용하지 않는다 (다른 치구 기준을 적용하는 오류가 된다). 상세는 PLAN.md.
